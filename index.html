Help

How do I turn on USB debugging?
  1. On the phone, open Settings → About phone.
  2. Find Build number and press it 7 times. You’ll see “You are now a developer”.
  3. Go back to Settings and open Developer options (sometimes under System).
  4. Turn on USB debugging.

On some flip phones (for example TCL and Alcatel), dial *#*#33284#*#* instead.

When you connect, the phone asks “Allow USB debugging?”. Tick Always allow from this computer and press Allow. On a flip phone the prompt can appear on the inside screen, so open the phone to see it.

“Another program is using the phone” or the connection fails
  • Only one program can talk to the phone at a time. If adb is installed on this computer, run adb kill-server in a terminal, then try again.
  • Close other tabs or apps that might be using the phone (Android Studio, phone managers).
  • Unplug the phone, plug it back in, and click Connect phone again.
  • Try a different cable or USB port. Some cables only charge and can’t carry data.
My phone doesn’t appear in the list (Windows)

Windows sometimes needs a USB driver before the browser can see the phone. Install the Google USB Driver or the phone maker’s own USB driver, then unplug and replug the phone.

On the phone, also make sure the USB mode is set to File transfer or Charging only with USB debugging still on.

The phone never shows “Allow USB debugging?”
  • Open or unlock the phone. The prompt only shows on an unlocked screen.
  • In Developer options, use Revoke USB debugging authorizations, then unplug, replug and connect again.
Is this safe? What does it do to my phone?

Everything runs in this browser tab. The page talks straight to the phone over the USB cable; nothing is sent to a server. Each app’s Read more lists the exact commands it runs on the phone. You can turn USB debugging off again when you’re done.
